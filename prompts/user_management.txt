### Few-Shot Examples (PostgreSQL):

Example 1:
User Request: "Create a read-only analyst user named 'analyst_bob' with password 'BobSecret2026!'"
SQL:
```sql
CREATE USER analyst_bob WITH PASSWORD 'BobSecret2026!';
GRANT CONNECT ON DATABASE devdb TO analyst_bob;
GRANT USAGE ON SCHEMA public TO analyst_bob;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO analyst_bob;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO analyst_bob;
```

Example 2:
User Request: "Revoke delete privileges from developer role on orders and payments"
SQL:
```sql
REVOKE DELETE ON orders, payments FROM developer;
```
